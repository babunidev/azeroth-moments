# Azeroth Moments — development and documentation rules

**Author:** Babuni.dev

Preserve original captured media; distinguish Discord uploads of originals from Instagram-specific derivatives. Attribute the publishing concept, constraints and gameplay capture to Babuni.dev; list AI implementation and technical analysis separately. Never infer success from an API timeout or an ambiguous remote publication. Keep secrets, API tokens and webhook credentials out of Git. Alongside substantial changes, maintain README, CONCEPT, ROADMAP, CHANGELOG and docs/DEVLOG, and record actual tests and publication evidence.
